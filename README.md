# Smart CV Studio

Build a complete production-ready, mobile-first Smart CV Builder web app exactly as requested: React/Tailwind/shadcn/Lucide/Framer Motion, instant English/Arabic LTR/RTL toggle, automatic localStorage persistence, multi-step CV wizard with all specified dynamic sections and avatar preview, rich summary with simulated AI polish, live preview and mobile/desktop preview switcher, four distinct professional templates, reliable A4 client-side PDF export, fixed responsive AdMob banner placeholder id="admob-banner-slot", and a 5-second rewarded-ad modal gate before PDF download and premium-template unlock. Use a polished modern SaaS visual system: deep indigo #4F46E5, slate #F8FAFC, emerald accents, glass cards, high contrast. On mobile provide Edit/Preview tabs; on desktop a side-by-side split workspace. Make it feel complete and test interaction states.
